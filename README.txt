FLOW PLAY — LIQUID GLASS ROCK PAPER SCISSORS

1. Extract the ZIP file.
2. Keep index.html, style.css, script.js, and liquid-background.jpg in the same folder.
3. Open index.html in your browser, or open the folder in VS Code and run Live Server.

Controls: click Rock/Paper/Scissors, or press R/P/S. Press N for a new game.
Game stats are stored in your browser using localStorage.
